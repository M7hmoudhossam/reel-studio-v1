# Reel Studio v1

تطبيق محلي يحوّل موضوعًا إلى ريل علمي رأسي باللهجة المصرية. الواجهة عربية، والرسم حتمي باستخدام Canvas وPlaywright وffmpeg.

## التشغيل

يلزم Node.js 18.17 أو أحدث واتصال للتثبيت الأول. في Windows افتح `start.bat`؛ أو من داخل المجلد:

```bash
npm run setup
npm start
```

افتح **http://127.0.0.1:4301/**. الخادم يستمع على localhost فقط. التثبيت ينفّذ `npm install` وتنزيل Chromium؛ لو فشل التنزيل يستخدم Google Chrome المثبّت. على Linux قد يلزم `npx playwright install-deps chromium` بصلاحيات المدير. يُستخدم ffmpeg من PATH أو النسخة التي تثبّتها حزمة npm؛ ويمكن تحديد مساره في الإعدادات.

## الإعداد والعمل

1. من **الإعدادات والمفاتيح** اضبط FreeLLMAPI على `http://127.0.0.1:31415/v1` و`auto`، أو أي خادم OpenAI-compatible يدعم البث. [إعداد FreeLLMAPI](https://github.com/tashfeenahmed/freellmapi).
2. أضف مفتاح [ElevenLabs](https://elevenlabs.io/app/developers/) واضغط «تحميل الأصوات» واختر صوتًا مناسبًا للعربية. للصوت المرفوع أضف مفتاح [Deepgram](https://console.deepgram.com/).
3. اكتب الموضوع، اختر المدة والصوت وسياسة الموافقة لكل مرحلة. يمكنك تعديل النص والتوقيت وخطة JSON، وإعادة أي مرحلة أو إلغاء التنفيذ. التعديل يمسح نتائج المراحل اللاحقة. الكلمات ضعيفة المحاذاة معلّمة للمراجعة، وكذلك توقيتات ElevenLabs إذا تم تسريع الصوت لأنها تصبح تقريبية.
4. حمّل MP4 من المعاينة. توقيت الإضاءة يعتمد على توقيت المزود ويُكمّم إلى أقرب إطار تالٍ (بحد أقصى 1/30 ثانية). لو كان الصوت أطول من المدة يُسرّع بما لا يتجاوز ×1.6؛ وإلا يلزم اختصار النص أو زيادة المدة. راجع المعلومات والمصادر قبل النشر.

تُحفظ الإعدادات في `data/settings.json`، ويمكن نسخ `.env.example` إلى `.env` بدلًا منها؛ القيم المحفوظة تتقدّم على `.env`. المتصفح لا يسترجع المفاتيح إلا مقنّعة بآخر ٤ أحرف. **الملف المحلي ليس مشفّرًا**؛ لا تشاركه. النص يُرسل إلى نموذج اللغة وElevenLabs، والصوت المرفوع إلى Deepgram. قد تترتب رسوم أو شروط من هذه الخدمات.

## اختبار بلا إنترنت

أغلق التطبيق أولًا لتحرير المنفذين 4301 و4399، ثم:

```bash
npm test
npm run e2e
npm run contact-sheets
```

تشغّل اختبارات التكامل خدمات وهمية على localhost فقط. نص الاختبار ثابت عن القلب، والصوت التجريبي آلي مولّد محليًا بـ eSpeak NG؛ **ليس** صوت ElevenLabs، ولا يعني نجاح الاختبار التحقق من مفاتيح أو استجابات الخدمات الحقيقية. `e2e` يختبر الموافقة والمزامنة والصوت المرفوع والإلغاء ويكتب `output/reel-test-10s.mp4`. صفحات التلامس للقوالب التسعة في `tests/contact-sheets/`؛ لكل قالب مشروع اختبار يتوقف عند مراجعة المشاهد وأربع لقطات، وليس تسعة فيديوهات كاملة. لإعادة فتح مشروع اختبار انسخ مجلده من `tests/template-projects/` إلى `data/projects/`.

الخط المرفق **IBM Plex Sans Arabic** بترخيص OFL؛ يمكن وضع المسار الكامل لمجلد خط عربي آخر في الإعدادات. تراخيص الخط والأيقونات داخل `assets/`، ومكتبة الأيقونات تجمع رسومات أصلية وHealth Icons ‏(CC0) وTabler ‏(MIT). دليل أسلوب النص في `references/script-style.md`.
