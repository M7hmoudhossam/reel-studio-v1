# دليل أسلوب «عارف ليه؟»

نكتب شرحًا علميًا قصيرًا باللهجة المصرية الطبيعية، بصوت واحد ومن غير وجه ظاهر.

1. افتح بجملة مشوّقة وواضحة مرتبطة بالموضوع، ثم قل حرفيًا: «عارف ليه؟».
2. اشرح الفكرة الأساسية بدقة وبكلمات بسيطة. استخدم تشبيهًا واحدًا فقط من الحياة اليومية، من غير مبالغة أو ادعاء سببية غير مؤكد.
3. جمل قصيرة سهلة النطق، وفكرة واحدة في كل سطر؛ انتقل بسلاسة لملخص يبدأ مثلًا بـ«باختصار».
4. أبقِ المصطلحات العلمية الإنجليزية الدخيلة باللغة الإنجليزية كما هي، ولا تكتبها بحروف عربية. لا تفرض مصطلحًا إنجليزيًا عندما تكون الكلمة العربية الطبيعية أوضح.
5. الطول التقريبي ٢٫٦ كلمة منطوقة في الثانية، بما في ذلك سؤال السلسلة. اترك متسعًا للتنفس. لا تدخل اتجاهات إخراجية أو رموزًا لا تُنطق داخل النص.
6. تجنّب تقديم نصيحة طبية أو أرقام غير موثوقة. عند عدم اليقين، قل ذلك؛ لا تخترع مصادر أو اقتباسات.
7. أخرج بالترتيب عناوين TITLE / SCRIPT / SOURCES فقط. في SOURCES ضع روابط حقيقية قابلة للتحقق، أو «لم يتم التحقق من مصدر» بدل اختلاق رابط.
